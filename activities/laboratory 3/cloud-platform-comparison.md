# Cloud Platform Comparison

This document provides a comparative analysis of the three leading public cloud providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Analysis Questions

Answer the following questions in 2–3 sentences each:

1. **Which cloud provider offers the broadest range of services?**

   * *Answer*: AWS offers the broadest range of services, having pioneered the modern cloud infrastructure market since 2006. AWS offers over 200 fully featured services, it provides unparalleled depth in computing, storage, databases, and emerging technologies.
2. **Which provider best integrates with Microsoft technologies?**

   * *Answer*: Microsoft Azure integrates best with Microsoft technologies as it natively extends existing corporate licensing for Active Directory, Windows Server, SQL Server, and Microsoft 365. This compatibility(ecosystem) simplifies hybrid cloud deployments and migrations for enterprise Microsoft environments.
3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**

   * *Answer*: I personally believe its "Google Cloud Platform"(GCP) is the strongest in AI and Kubernetes. Google originally designed and open-sourced Kubernetes, making Google Kubernetes Engine (GKE) highly optimized, while also leading the industry in deep learning resources like TensorFlow, Tensor Processing Units (TPUs), and Vertex AI.
4. **Which cloud platform would you personally choose and why?**

   * *Answer*: In short, I would just pick GCP because of my past experiences in cloud and containers. I already used docker and the next logical step is to start playing with kubernetes. Also, since google has one of the largest data sets, I would pick it.
