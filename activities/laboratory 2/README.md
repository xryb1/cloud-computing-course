# Laboratory Activity 2 Summary: Welcome to the Cloud

This is a summary of the tasks and checkpoints required for **Laboratory Activity 2 (Mission 1: Welcome to the Cloud)**. Use this as a reference guide when performing the activity.

---

## Mission Objectives

- Access a cloud-based Linux environment using **KillerCoda**.
- Learn basic navigation and system gathering commands.
- Organize folders and configure users.
- Prepare documentation for your portfolio.

---

## Required Tasks & Checkpoints

### 1. Checkpoint 1: Access Linux & User Configuration

- **Task**: Launch the Linux Playground on KillerCoda (Ubuntu 24.04).
- **Task**: Create a new user with admin permissions (sudo).
  - *Username format*: Initial of FirstName + Surname (e.g., `bbryx`).
- **Task**: Log in to this new account and record:
  - Current Username
  - Current Working Directory
  - Hostname
- **Screenshot needed**: Save as `img-1.png` showing the terminal output.

### 2. Checkpoint 2: System Information Gathering

- **Task**: Find and note down the following system specifications:
  - Linux Distribution (e.g., Ubuntu version)
  - Kernel Version
  - CPU Information
  - Total Memory (RAM)
  - Available Disk Space
- **Screenshot needed**: Save as `img-2.png`.

### 3. Checkpoint 3: Build Workspace & About Me

- **Task**: Create a basic directory structure in your Linux home folder.
- **Task**: Write a short personal introduction (name, course, background) in a file named `about-me.md`.
- **Screenshot needed**: Save as `img-3.png` showing the terminal viewing `about-me.md`.

### 4. Checkpoint 4 & 5: Repository Setup & Documentation

- **Task**: Ensure these files and folders are structured cleanly under your repository's lab folder.
- **Screenshot needed**: Save as `img-4.png` (GitHub repository homepage) and `img-5.png` (file structure).
